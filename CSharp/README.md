# Arcscript C# Interpreter

The C# interpreter executes Arcscript embedded in the HTML generated by the Arcweave editor. It can evaluate conditions, update global and scoped variables, render output, read visit counts, and emit runtime events.

## Prerequisites

- .NET 6 SDK or newer
- Java 11 or newer for running the ANTLR generator
- Python 3 when using the repository-level generation scripts

The project restores the ANTLR C# runtime and test dependencies through NuGet.

## Building

Generate the ANTLR sources from the repository root, then restore and build the C# project:

```bash
sh generate.sh
dotnet restore CSharp/CSharp.csproj
dotnet build CSharp/CSharp.csproj --configuration Release
```

On Windows, run `generate.ps1` instead of `generate.sh`.

The current `CSharp.csproj` contains both the interpreter and its NUnit test suite. Applications can reference the project while developing in this repository, or integrate the interpreter sources and the `Antlr4.Runtime.Standard` dependency into their own project structure.

## Quick Start

Create the Arcweave project model, construct an `AwInterpreter`, and pass Arcscript as an HTML fragment containing `<pre><code>` elements:

```csharp
using System;
using System.Collections.Generic;
using Arcweave.Interpreter;
using Arcweave.Interpreter.INodes;
using Arcweave.Project;

var health = new Variable("health-id", "health", 100)
{
    Value = 75,
};

var project = new Arcweave.Project.Project(
    new List<Board>(),
    new List<Variable> { health }
);

var interpreter = new AwInterpreter(project);
var result = interpreter.RunScript(
    "<pre><code>health -= 10</code></pre>" +
    "<pre><code>show(health)</code></pre>"
);

Console.WriteLine(result.Output);
Console.WriteLine(result.Changes["health-id"]);
```

The example renders `<p>65</p>` and records `65` under the stable variable ID `health-id`.

## Project Model

`AwInterpreter` receives an implementation of `IProject`. The provided `Arcweave.Project.Project` model contains:

| Collection | Description |
| --- | --- |
| `Variables` | Global Arcscript variables. |
| `Boards` | Boards containing elements, variables, and attributes. |
| `Components` | Components containing variables and attributes. |

The standard constructors use `List<T>` collections:

```csharp
var project = new Arcweave.Project.Project(
    boards,
    globalVariables,
    components
);
```

The components argument is optional and defaults to an empty list.

## Variables

Create variables with a stable ID, an Arcscript name, and a non-null default value:

```csharp
var score = new Variable("score-id", "score", 10);
```

The runtime type is inferred from the constructor value. The interpreter currently supports the variable value types used by Arcscript: `string`, `int`, `double`, and `bool`.

### Current and Default Values

The constructor value becomes both `Value` and `DefaultValue`. To restore persisted state while preserving the original reset value, assign `Value` after construction:

```csharp
var score = new Variable("score-id", "score", 10)
{
    Value = 25,
};

var project = new Arcweave.Project.Project(
    new List<Board>(),
    new List<Variable> { score }
);

var result = new AwInterpreter(project).RunScript(
    "<pre><code>reset(score)</code></pre>"
);

var resetValue = (int)result.Changes["score-id"];
// resetValue == 10
```

`reset()` and `resetAll()` return changes keyed by variable ID. They do not mutate the caller's `Variable.Value` property automatically.

### Applying Changes Between Runs

Apply returned changes to the project model before creating state for a later invocation:

```csharp
var firstResult = interpreter.RunScript(
    "<pre><code>health -= 10</code></pre>"
);

var variablesById = new Dictionary<string, Variable>();
foreach (var variable in project.GetAllVariables())
{
    variablesById[variable.Id] = variable;
}

foreach (var change in firstResult.Changes)
{
    variablesById[change.Key].Value = change.Value;
}

var secondResult = interpreter.RunScript(
    "<pre><code>show(health)</code></pre>"
);
```

## Board and Component Variables

Board and component variables use the container's `CustomId` as their Arcscript scope:

```csharp
var board = new Board(
    "board-id",
    new List<INode>(),
    "inventory"
);
board.AddVariable(new Variable("board-gold-id", "gold", 20));

var component = new Component("player");
component.AddVariable(new Variable("player-health-id", "health", 100));

var project = new Arcweave.Project.Project(
    new List<Board> { board },
    new List<Variable>(),
    new List<Component> { component }
);

var result = new AwInterpreter(project).RunScript(
    "<pre><code>inventory.gold += 5</code></pre>" +
    "<pre><code>player.health -= 10</code></pre>"
);
```

The returned changes use `board-gold-id` and `player-health-id`, not the Arcscript names. Scope identifiers should be unique across boards and components supplied to one project.

## Interpreter Results

`AwInterpreter.RunScript()` returns `AwInterpreter.TranspilerOutput`:

| Property | Description |
| --- | --- |
| `Output` | Rendered HTML produced by content and `show()`. |
| `Changes` | Variable updates keyed by stable variable ID. |
| `Result` | The evaluated result, including boolean condition results. |

### Conditions

For condition input, cast `Result` to `bool`:

```csharp
var result = interpreter.RunScript(
    "<pre><code>health > 0</code></pre>"
);

var isAlive = (bool)result.Result;
```

## Visits and Events

Add `Element` instances to boards and set their persisted visit counts. Pass the current element ID to `AwInterpreter` so `visits()` can read it without an argument:

```csharp
var currentElement = new Element("current-element-id")
{
    Visits = 3,
};

var board = new Board(
    "board-id",
    new List<INode> { currentElement },
    "main"
);

var project = new Arcweave.Project.Project(
    new List<Board> { board },
    new List<Variable>()
);

var interpreter = new AwInterpreter(
    project,
    "current-element-id",
    eventName =>
    {
        if (eventName == "resetVisits")
        {
            Console.WriteLine("Visit counters were reset.");
        }
    }
);

var result = interpreter.RunScript(
    "<pre><code>show(visits())</code></pre>"
);
```

`resetVisits()` sets every project element's `Visits` value to zero and emits the `resetVisits` event.

## Error Handling

Parsing and runtime failures use separate exception types:

```csharp
try
{
    var result = interpreter.RunScript(code);
}
catch (ParseException error)
{
    Console.Error.WriteLine($"Invalid Arcscript: {error.Message}");
}
catch (RuntimeException error)
{
    Console.Error.WriteLine($"Arcscript execution failed: {error.Message}");
}
```

## Godot Integration

The source contains conditional `GODOT` implementations for Godot object and collection types. The standard `CSharp.csproj` builds and tests the non-Godot path; it does not reference the Godot SDK or validate a downstream Godot project.

Godot integrations should define `GODOT`, reference the matching Godot assemblies, and run their own build and runtime tests after importing the interpreter sources.

## Running Tests

Run the NUnit suite from the repository root:

```bash
dotnet test CSharp/CSharp.csproj --configuration Release
```

The suite covers valid scripts, member variables, conditions, string operations, parse errors, runtime errors, output rendering, visits, events, reset behavior, and board/component variable integration.
